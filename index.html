01 — About

Self-taught, detail-obsessed, and happiest when markup, styles and scripts click into place.

I started as a web designer in 2012 and have led front-end work at Mejora Infotech since 2014. My day is a mix of writing code, scoping requirements with clients, and helping my team ship themes that are clean to maintain and quick to load.

I'm fluent in HTML5, CSS3, SCSS, JavaScript and jQuery, and I've grown up with the tooling — npm and Bower for packages, Gulp, Grunt and Compass for builds, and Jekyll or Middleman when a project calls for a static site.

02 — What I do

/01

Custom WordPress themes

Hand-built themes from design files — ACF-driven layouts, tidy templates and an admin that clients can actually use.

/02

SCSS architecture

Nested, modular stylesheets with tokens and partials, so a site stays consistent long after launch.

/03

Performance & Core Web Vitals

Mobile-first tuning for PageSpeed — leaner assets, smarter loading and layouts that don't shift.

/04

Leading front-end teams

Scoping with clients, setting conventions, reviewing code and keeping delivery on track.
